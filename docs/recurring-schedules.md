# 정기거래 기간·회차·영업일

규칙 저장은 거래를 생성하지 않는다. 기존과 같이 내역에서 선택한 월의 정기거래를 반영할 때만 원장에 들어간다. 별도 스케줄러나 미래 거래 선입력은 없다.

## 설정

- 시작 월·종료 월은 모두 포함한다. 빈 값은 해당 방향으로 제한이 없다. 사용 해제는 기간과 무관하게 생성을 막는다.
- 시작 회차는 선택 사항이다. 설정하면 시작 월과 제목의 `X회` 표시가 필요하다. 회차는 시작 회차 + 두 월의 차이로 계산하므로 재실행·역순 반영·건너뛴 월에 영향을 받지 않는다. 회차를 설정하지 않은 기존 `X회`·`X월` 제목은 그대로 유지한다.
- 휴일 조정은 `조정 안 함` / `이전 영업일` / `이후 영업일` 중 선택한다. 지정일(없는 일자는 월말)이 영업일이면 그대로 유지하고, 아니면 선택한 방향으로 토·일·공휴일·대체공휴일·근로자의 날을 건너뛴다.
- 날짜가 전월·다음 달·다른 연도로 넘어가도 회차·종료 월·반영 여부와 멱등 키 `recurring:{규칙ID}:{YYYY-MM}`는 원래 예정 월 기준이다. 거래일만 실제 조정된 날짜로 저장한다. 미반영 선택 창·실제 반영·AI 예산의 예정일은 같은 계산을 사용한다.
- 휴일 설정 변경은 이미 생성된 거래의 날짜를 바꾸지 않는다. 기존 조정 꺼짐/이전 영업일 규칙도 그대로 유지한다.
- 종료 후에도 규칙과 생성된 거래는 삭제하지 않는다. 해당 월의 미반영 건수·합계·홈 알림에서만 제외한다.
- 기존 규칙은 시작·종료 제한 없음, 자동 회차 없음, 영업일 조정 꺼짐으로 유지한다. 모든 규칙에서 개별 설정할 수 있다.

## 공휴일 자료

우주항공청 월력요항 기반 [@hyunbinseo/holidays-kr](https://github.com/hyunbinseo/holidays-kr) `5.2027.1`의 2018~2027년 데이터를 패키지에 포함해 사용한다. 반영 시 외부 네트워크에 의존하지 않는다. [2027년 공식 월력요항](https://www.kasa.go.kr/bbs/BBSMSTR_000000000018/B000000003234Li6nD2.do?mno=sub01_03_03)을 참고한다.

자료가 없는 연도의 영업일 조정은 오류를 표시하고 그 월의 일괄 반영 전체를 취소한다. 해당 연도 자료가 발표되거나 임시공휴일이 추가되면 패키지 업데이트 및 회귀 검증이 필요하다. 일반 지정일 규칙은 이 제한의 영향을 받지 않는다.

## 배포

`drizzle/0010_recurring_business_day_direction.sql`은 `business_day_direction` 열과 `previous`/`next` 제약을 추가한다. 기본값 `previous`로 기존 `adjust_to_business_day` 설정의 동작을 보존한다. 운영 백업 후 이 마이그레이션을 먼저 적용하고 새 코드를 배포한다. 새 `이후 영업일` 규칙은 새 코드 배포 후 설정한다. 이전 버전으로 롤백할 때는 `이후 영업일` 규칙을 먼저 비활성화해야 한다(구버전은 방향을 읽지 않고 이전 영업일로 처리). 추가 열은 남겨 둔다.

`drizzle/0006_recurring_schedule.sql`은 `recurring`에 nullable 열 3개, 기본 false 열 1개 및 무결성 제약을 추가한다. 기존 거래·규칙을 변경하지 않는다. 운영 백업 후 마이그레이션을 먼저 적용하고 애플리케이션을 배포한다. 새 기간 제한 규칙은 새 코드가 배포된 후 등록한다. 이전 코드에는 기간 필터가 없어 새 규칙을 먼저 활성화하면 안 된다.

코드를 이전 버전으로 되돌릴 때는 기간·회차·휴일 조정이 설정된 규칙을 먼저 비활성화하고 백업한다. 추가된 열은 데이터 보존을 위해 남겨 둔다. 일반 규칙과 이미 반영된 거래는 유지한다.

## 검증

- 단위: 기간 경계, 역순 회차, 기존 제목 보존, 입력 검증, 양방향 휴일 조정·전월/다음 달/연도 이동, 미지원 연도.
- 통합: 저장만으로 거래 0건, 마지막 회차, 범위 밖 미생성, 중복 방지, 홈 집계, 구버전 폼의 설정 보존 및 유효성 검사, 달력 오류의 원자성.
- E2E: 새 규칙 입력→저장·새로고침→9월/마지막 월 반영→종료 후 버튼 없음, 모바일 폭.
