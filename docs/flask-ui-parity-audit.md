## 이미 동등하거나 확장된 영역

- 인박스 월별 접기/펼치기, 전체 선택, 중복 의심 기본 해제, flow 전환, 분류·계정 추천
- 뱅크샐러드와 5개 카드사 명세서 업로드, 자산 스냅샷 upsert
- 대시보드 항목별 월 표의 hover/focus 거래 툴팁, 터치용 내역 버튼, 합계 제외 토글
- 차트 legend 표시/숨김과 hover 강조, 결제수단별 월 추이, 재무건강 신호등
- 예산 지난달/평균 채우기, 실시간 저축률 계산, 변동비 감축 시뮬레이터, sticky 리뷰 합계
- 카테고리 상세, 가맹점 분석, 이상지출, 연간결산과 현금흐름 예측

## 의도적으로 동일 구현을 피한 부분

- Flask의 대분류/소분류 2개 select는 좁은 표에서 오조작이 잦아, 거래 인라인 편집과 인박스에서는 `대분류 · 소분류` 한 개 select를 유지했다. 계층 정보와 flow 제한은 동일하다.
- Chart.js 자체는 복제하지 않고 기존 접근 가능한 SVG 차트를 유지했다. legend·tooltip·필터 결과는 같은 사용 시나리오를 지원한다.
- 가져오기 전용 페이지는 만들지 않고, 인박스 상단 업로드 섹션을 설정 팝오버의 `가져오기`에서 바로 연결한다.
