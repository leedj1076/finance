## Global Constraints

- 색은 토큰만: ink `#18181b`, muted `#71717a`, faint `#a1a1aa`, hairline `#e4e4e7`, track `#f4f4f5`, blue `#2563eb`, red `#dc2626`, green `#16a34a`, amber `#d97706`. Tailwind 클래스는 `text-finance-*` / `bg-finance-*` / `border-finance-*`.
- **버튼 규칙**: 채운 검정(`bg-finance-ink text-white`) = 주 버튼. 채운 초록은 **월 마감 확정 버튼 한 곳**(`month-close-control.tsx`의 `월 전체 마감`)만. 채운 파랑 버튼은 없다(파랑은 텍스트 링크와 수입 숫자). 비활성은 `disabled:opacity-40`, 색을 바꾸지 않는다.
- **색 의미**: 빨강 = 초과·음수·오류. 초록 = 저축·달성·확정. 파랑 = 수입·링크. 주황 = 경고·잠정. 평범한 지출 행, 건수, 진행 막대는 검정·회색.
- **숫자**: 히어로(t-hero, t-kpi) 금액은 `formatWonCompact`로 억·만 단위, 정확한 금액은 캡션. 표·목록의 금액은 `formatWon` 그대로. 음수 기호는 U+2212 `−` 하나.
- 원시 `text-[Npx]` 새로 쓰지 않는다. `t-*` 타입 스케일 사용.
- 각 태스크 끝에 `NODE_OPTIONS= pnpm exec tsc --noEmit`, `NODE_OPTIONS= pnpm lint`, 해당 테스트 통과 후 커밋. 태스크 단위 커밋, 메시지는 `style(scope): …` / `feat(scope): …`.
- `git add`는 플랜에 적힌 경로만. 다른 세션의 untracked 파일(`docs/superpowers/plans/2026-09-07-*`, `docs/design/swiss-ledger/ai-diagnosis-*`, `outputs/`)은 포함하지 않는다.

```ts
export const MINUS = '−'

/** Negative amounts read with a real minus sign; nothing is prefixed to zero or positives. */
export function formatSigned(value: number, formatter: (value: number) => string = formatWon) {
  return value < 0 ? `${MINUS}${formatter(Math.abs(value))}` : formatter(value)
}

/**
 * Hero figures: 4,708만원 reads at a glance, 47,080,000원 has to be counted.
 * The exact amount belongs in the caption next to it.
 */
export function formatWonCompact(value: number): { text: string; unit: '원' | '만원' | '억원' } {
  const sign = value < 0 ? MINUS : ''
  const absolute = Math.abs(Math.round(value))
  if (absolute >= 100_000_000) {
    const eok = absolute / 100_000_000
    const text = Number.isInteger(eok) ? String(eok) : eok.toFixed(1)
    return { text: `${sign}${text}`, unit: '억원' }
  }
  if (absolute >= 10_000_000) return { text: `${sign}${formatWon(Math.round(absolute / 10_000))}`, unit: '만원' }
  return { text: `${sign}${formatWon(absolute)}`, unit: '원' }
}
```
